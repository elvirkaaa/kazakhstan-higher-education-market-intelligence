# Table 3 — Bolashak Cumulative Graduates, by Field, Destination, and Level (as of 31 December 2024)

## Purpose
Summarise the Bolashak programme's full cumulative output in one reference table.

## Variables

## Key Observation
Master's-level (57.5%) and UK/Ireland-or-USA/Canada destinations (73.5% combined) dominate the cumulative Bolashak alumni base — see Figure 4 for the contrast with general inbound mobility.
