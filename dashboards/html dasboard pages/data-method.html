Data & Method

From raw records to an analytical dataset

The project combines datasets that were collected for different purposes, recorded at different geographic levels, and measured using non-equivalent definitions.

Covers: WP1-WP3 · This page documents how, not just what

01 · PipelineHow 8,530 raw records became an analytical dataset

8,530
Raw Data
Programme registration records
One row per registration event, not per programme — the OPVO/EPVO export includes re-registrations, price updates, and status changes for the same underlying programme.
?
Data Audit
Duplicates, missing fields, inconsistent pricing
1,304 groups contained more than one row for what was clearly the same programme. 13 institutions showed zero price variance across their entire catalogue — flagged as ambiguous (genuine flat fee vs. unpopulated field), not resolved by assumption.
3×
Deduplication
Grouping key: University + Programme Code + Degree Level
This exact key was chosen because it reproduced the total already independently confirmed in the official WP1 report tables — not an arbitrary threshold picked to look clean.
2,417
Result
Distinct programmes
A 71.7% reduction from raw rows. Validation check: this project's independently-derived count (2,417) was compared against the total stated in the official WP1 regional statistics report — the two figures match exactly, which is the strongest available check given no third-party dataset exists to cross-verify against.
📍
Regional Matching
No native region field — attribution by university city
The registry records each university, not its region. Region was inferred externally from each university's known home city, then mapped to the current post-2022 administrative structure (15 of 20 regions hold at least one university).
→
Output
Analytical dataset
Joined against demographic and mobility datasets for the Cross-Analysis page — each join documented, each mismatch flagged rather than silently resolved.

03 · Data ChallengesFour problems, four resolutions

01
Duplicate programme records
Resolution
Grouping and deduplication by University + Programme Code + Degree Level (8,530 → 2,417)
02
No native region field
Resolution
Geographic attribution by university home city, mapped to current administrative regions
03
Changing administrative boundaries (2018, 2022 reforms)
Resolution
Both boundary versions kept available; one reconstructed from the other transparently, with the reconstruction explicitly labelled
04
Non-equivalent mobility indicators
Resolution
Analysed separately rather than artificially combined — exchange, full-degree enrolment, and Bolashak scholarships each measure a different population
05
Flat/placeholder pricing in the registry
Resolution
13 institutions show zero price variance (e.g. Kazakh American Free University: 421 programmes, all KZT 620,000) — flagged as ambiguous rather than assumed either way
