Methodology & Data Limitations

What is shown

Net interregional migration: arrivals into a region from other regions of Kazakhstan, minus departures to other regions, for the most recent available year in the source table. This is internal migration only — it does not include international migration (covered separately) or international student mobility (covered under a separate work package of this project).

Data source

Bureau of National Statistics of the Republic of Kazakhstan, "Interregional population migration" table. The source file does not state its exact reference year explicitly; based on file metadata it most likely reflects 2024 or 2025.

Why two maps

Kazakhstan's administrative structure changed on 8 June 2022: three new regions (Abay, Zhetisu, Ulytau) were created by splitting East Kazakhstan, Almaty, and Karaganda respectively. Astana and Shymkent are cities of republican significance, administered separately from any oblast. A single map cannot correctly represent both the modern (20-unit) structure and any freely available older boundary file, which is why this dashboard provides two distinct views rather than forcing one geometry to represent both.

How the "Before Reform" view is constructed

This is reconstructed / aggregated data, not an original historical observation. The only migration data available to this project is the current, single-year, 20-unit dataset above. The "Before Reform" map is produced by summing the modern figures back into the 14-oblast structure that the available free boundary file (open-data-kazakhstan/geo-boundaries-kz, GADM-derived) can represent:

  • Almaty = Almaty city + Almaty Region + Zhetisu
  • Aqmola = Akmola + Astana
  • South Kazakhstan = Turkistan + Shymkent city
  • East Kazakhstan = East Kazakhstan + Abay
  • Qaraghandy = Karaganda + Ulytau

This is a geographic re-aggregation of current data, useful for showing the relationship between the two administrative structures — it is not a measurement of migration as it actually occurred under the old structure at some earlier date. The national sum of the aggregated values equals zero, which is mathematically expected for a zero-sum internal-migration measure and was verified computationally, not assumed.

Year coverage

Only one year of interregional migration data is currently available to this project (see Data source, above). The timeline at the top of this page shows the 2022 reform in context, not a working year selector — the code below is structured so a multi-year dataset (Year, Region, Net_Migration) can be added later without redesigning the dashboard, but no historical year-by-year values are fabricated here.
